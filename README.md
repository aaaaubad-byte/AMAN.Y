# AMAN | أمان — النسخة المحلية النظيفة

هذه معاينة تفاعلية محلية لاختبار تدفقات العميل والإدارة قبل ربط Android وSupabase. **لا تتصل بخادم أو بوابة دفع حقيقية، وليست نظام إنتاج.**

## تشغيل المشروع

1. فك ضغط الملف كاملًا.
2. شغّل `serve.sh` أو افتح الطرفية داخل مجلد المشروع ونفّذ `python3 -m http.server 8000`.
3. افتح `http://127.0.0.1:8000/apps/customer.html` لتطبيق العميل.
4. افتح `http://127.0.0.1:8000/apps/admin.html` للإدارة في تبويب آخر من المتصفح نفسه.
5. سجّل حساب العميل من واجهة العميل. سيظهر الحساب نفسه في الإدارة لأن التطبيقين يستخدمان مخزن `localStorage` مشتركًا على الأصل نفسه.

## الدخول إلى الإدارة

- البريد: `admin@aman.test`
- كلمة المرور: `admin1234`

هذه بيانات دخول محلية للمعاينة فقط، وليست حماية إنتاجية.

## تبدأ البيانات فارغة

لا تُنشأ تلقائيًا أي حسابات عملاء أو شركات أو باقات نقاط أو وسائل دفع أو أرقام أو اشتراكات أو طلبات أو معاملات مالية أو مهام أو إشعارات. أضف الشركات وباقات النقاط ووسائل الدفع يدويًا من شاشة **المزيد** في الإدارة، ثم أنشئ حساب العميل واختبر دورة الشراء والاعتماد بنفسك.

لا يوجد زر لإعادة تعبئة بيانات تجريبية في واجهات التطبيق. يستخدم المخزن المفتاح `AMAN_SHARED_REGISTRY_V2` لبدء مساحة عمل نظيفة بدل البيانات القديمة المحفوظة بالمفتاح السابق. افتح التطبيقين على العنوان نفسه والمتصفح نفسه حتى تتشارك البيانات.

## الأزرار العائمة في الإدارة

- **الرئيسية:** أيقونة المزيد تفتح شاشة المزيد.
- **المهام:** أيقونة المهام تفتح كل المهام.
- **الاشتراكات:** أيقونة الهاتف تفتح كل الأرقام المشتركة، وتوجد داخل الشاشة عملية إضافة رقم.
- **طلبات النقاط:** أيقونة سجل الطلبات تفتح كل طلبات الشراء.
- **المشتركون:** أيقونة المستخدمين تفتح قائمة كل العملاء والمستخدمين.

الأيقونة مرتبطة بمعنى الوجهة، وليست علامة (+) في جميع الشاشات. أزيلت اختصارات البطاقات التي كانت تكرر التنقل إلى الوجهات المخصصة للأزرار العائمة؛ بطاقات مؤشرات الرئيسية أصبحت للعرض فقط.

## تنبيهات مهمة

- كلمة مرور حساب العميل في هذا النموذج المحلي ليست بديلًا عن نظام مصادقة آمن.
- بيانات المتصفح مشتركة بين التطبيقين على الأصل نفسه فقط، ولا تتزامن بين أجهزة أو متصفحات مختلفة.
- مسح بيانات الموقع في المتصفح يمسح بيانات المعاينة.
- لا تدخل بيانات شخصية أو مالية حقيقية.
- الاختبارات الآلية تستخدم ملفًا منفصلًا داخل `tests/fixture-data.js`؛ هذا الملف مخصص للاختبارات ولا تحمّله صفحات العميل أو الإدارة.

## الاختبارات

من مجلد المشروع نفّذ:

```sh
node --test tests/core.test.js
```

تغطي الاختبارات قواعد العمل والتخزين والهوية البصرية وروابط الأزرار. نجاح الاختبارات الآلية لا يعني وحده إتمام اختبار قبول بصري شامل على كل جهاز.
