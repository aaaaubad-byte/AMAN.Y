# إصلاح الخطوط وفق المرجع 1.1

## سبب عدم التطابق
كان `customer-base.css` و`admin-base.css` يحددان الخط `Tahoma, Arial` لخط الصفحة ولشعار تسجيل الدخول، بينما المرجع 1.1 يحدد `Alexandria, 'DM Sans', sans-serif`. لذلك كانت بعض العناصر، خصوصًا شعار تسجيل الدخول والنصوص التي ترث خط الصفحة، لا تتبع خط المرجع بالكامل.

## التعديل
- توحيد خط الصفحة في واجهتي العميل والإدارة إلى `Alexandria, 'DM Sans', sans-serif`.
- توحيد خط شعار تسجيل الدخول في الواجهتين إلى الخط نفسه.
- الإبقاء على روابط تحميل الخطوط الموجودة في `customer.html` و`admin.html` كما هي.
- لم يتم تغيير أحجام الخطوط أو الأوزان أو الأيقونات ضمن هذا الإصلاح.

## التحقق
- فحص صياغة JavaScript: يُجرى ضمن أوامر التحقق.
- اختبارات المشروع: تُشغّل بعد التعديل، وتُسجل نتيجتها الفعلية عند التسليم.
- لم يُجرَ اختبار بصري حيّ داخل المتصفح؛ لذا لا يُدّعى تحقق التطابق المرئي الكامل.
