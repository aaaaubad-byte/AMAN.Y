- لم يجرِ في هذه الجولة اختبار قبول تفاعلي كامل عبر Chromium أو متصفح هاتف فعلي؛ محاولة تشغيل Chromium في بيئة التنفيذ لم تكتمل، لذلك لا أصف الواجهات بأنها اجتازت اختبارًا بصريًا حيًا.

- لا يوجد اتصال فعلي ببوابة دفع أو مشغل اتصالات أو Push/SMS.
- المخزن المحلي يشارك البيانات داخل المتصفح/الأصل نفسه فقط. لا توجد مصادقة إنتاجية أو صلاحيات آمنة ضد تعديل `localStorage`.
